MÉNDEZ TV RADIO — CONEXIÓN CASTER.FM GRATUITA
================================================

ESTA EDICIÓN ES PARA LA VERSIÓN GRATIS DE CASTER.FM.
La opción Direct Stream Link está BLOQUEADA en el plan gratuito.
En cambio, se utiliza el reproductor oficial incrustado de Caster.fm.

1. Entra a tu panel de Caster.fm, busca «Widgets» / «Embed Player»
   o «API Tokens» / «Public Token».
2. Copia exclusivamente el TOKEN PÚBLICO de Caster.fm.
   No copies la contraseña de emisión ni tu token privado.
3. En GitHub, abre el archivo config.js, pulsa el lápiz y busca:
   casterPublicToken: '',
   Pega el token público entre las comillas.
4. Pulsa «Commit changes».
5. Si todavía no actualizaste esta edición del sitio, sube los archivos
   index.html, config.js, sw.js y LEEME-PRIMERO.txt a la raíz del
   repositorio (sobrescriben los anteriores).
6. Abre la web y haz clic en PLAY en el reproductor oficial.

NOTA: «Streaming Server Online» no significa que hay música sonando.
También debes estar transmitiendo desde Mixxx/BUTT/RadioBOSS con tu
usuario y contraseña de emisión, usando un bitrate <= 96 kbps.

Si usas un proveedor distinto con URL pública HTTPS directa, puedes
seguir usando el reproductor personalizado mediante «streaming».
Si tienes casterPublicToken configurado, prevalece el widget de Caster.fm.

Alojamiento web: GitHub Pages, gratuito.
Servidor de radio: Caster.fm, gratuito, con limitaciones del plan.
El reproductor integrado pertenece a Caster.fm y requiere internet.
